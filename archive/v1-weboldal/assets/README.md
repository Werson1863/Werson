# Márka-assetek (forrás)

- `logo/` – SVG logók. **A jelenlegiek helykitöltők**, írd felül őket azonos névvel (lásd TODO.md).
- `photos/` – az alapító fotói eredeti felbontásban. **A jelenlegiek helykitöltők.**
  Elvárt alapnevek: `peter-portre-szines`, `peter-teljes-alakos`, `peter-portre-ff` (jpg/png/webp).

A `npm run assets` (dev/build előtt automatikusan fut) ezekből generálja a `public/brand/` és
`public/images/team/` tartalmát – azokat ne szerkeszd kézzel.
