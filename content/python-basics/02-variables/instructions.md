# Változók

A Pythonban egy értéket egy névhez rendelhetünk `=` jellel — ezt hívjuk változónak.

```python
name = "Ada"
print(name)
```

## Feladat

Hozz létre egy `age` nevű változót a **7** értékkel, majd írasd ki a `print()` függvénnyel.

## Elvárt eredmény

A kimenetben szerepelnie kell a `7` értéknek, és a kódnak valóban egy `age` nevű változót kell használnia.
