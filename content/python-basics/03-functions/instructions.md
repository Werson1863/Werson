Egy függvényt a `def` kulcsszóval definiálhatunk. A `return` adja vissza az eredményt a hívónak.

```python
def add_one(n):
    return n + 1
```

## Feladat

Írj egy `square(n)` nevű függvényt, amely visszaadja a paraméter **négyzetét** (`n * n`).

## Elvárt eredmény

A `square(4)` hívásnak `16`-ot kell visszaadnia.
